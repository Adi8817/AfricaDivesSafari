# Africa Dive Safaris — Prototype

Static HTML/CSS/JS prototype, built section-by-section for eventual WordPress theming.

## Structure
- `index.html`, `about.html`, `contact.html` — pages
- `assets/css/style.css` — all styles
- `assets/js/main.js` — interaction scripts only (no content generation)
- `assets/images/{hero,sections,gallery,icons}` — image assets

## Status
Structure only. Sections added progressively per approved screenshot.
